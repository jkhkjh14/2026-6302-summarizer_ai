# 🤖 ИИ-суммаризатор текста

Веб-приложение для автоматического сокращения (суммаризации) текстов из различных источников с использованием генеративной модели YandexGPT.

---

## 📌 Описание проекта

Сервис позволяет быстро получить краткое изложение больших текстов. Пользователь может:

* Ввести текст вручную;
* Указать URL статьи (например, Википедия);
* Загрузить файл: `.txt`, `.pdf`, `.docx`, `.jpg`, `.png` (с распознаванием текста);
* Выбрать желаемую степень сжатия (кратко / средне / подробно / своё значение);
* Скачать результат в формате `.txt` или `.docx`.

Приложение решает реальную задачу: экономит время при работе с большими объёмами информации.

## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/jkhkjh14/2026-6302-summarizer_ai.git
cd 2026-6302-summarizer_ai
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
python -m venv venv
```

Активация:

* **Windows**: `venv\Scripts\activate`
* **Linux/macOS**: `source venv/bin/activate`

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Для работы с YandexGPT вам понадобится API-ключ и идентификатор каталога в Яндекс.Облаке.

1. Создайте сервисный аккаунт в Яндекс.Облаке и назначьте ему роль `ai.languageModels.user`.
2. Сгенерируйте API-ключ.
3. В корне проекта создайте файл `.env` со следующим содержимым:

```env
YANDEX_FOLDER_ID=ваш_folder_id
YANDEX_API_KEY=ваш_api_ключ
```

> **Важно:** Файл `.env` не должен попадать в репозиторий (он уже добавлен в `.gitignore`).

Для примера в репозитории есть файл `.env.example` с шаблоном.

### 5. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу:

http://127.0.0.1:5000

## 🏗️ Архитектура решения

Проект построен по классической клиент-серверной модели:

* **Backend**: Flask (Python) — обрабатывает запросы, управляет логикой, взаимодействует с внешними API.
* **Frontend**: HTML + Bootstrap 5 (адаптивный интерфейс).

### Основные модули

* **Модуль извлечения текста**:

  * Для URL: `newspaper3k` + `BeautifulSoup`
  * Для файлов: `PyPDF2`, `python-docx`
  * Для изображений: `EasyOCR` (с предварительным сжатием)

* **Модуль суммаризации**: отправляет текст в YandexGPT с динамическим промптом в зависимости от желаемой длины.

* **Модуль экспорта**: генерация `.txt` и `.docx` из полученного пересказа.

### Схема работы

```text
Пользователь → Веб-интерфейс → Flask → Извлечение текста → YandexGPT → Результат → Скачивание
```

## ⚠️ Известные ограничения

* Максимальная длина обрабатываемого текста ограничена **15 000 символов** (для избежания ошибок API).
* Некоторые политически чувствительные темы могут блокироваться YandexGPT.
* Качество распознавания текста с изображений зависит от чёткости и контрастности.
